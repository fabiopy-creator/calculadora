🧮 Calculadora Web
Calculadora visual moderna feita com HTML, CSS e JavaScript puro — sem frameworks, sem bibliotecas externas.

✨ Funcionalidades
Soma, subtração, multiplicação e divisão
Porcentagem, raiz quadrada e inversão de sinal
Histórico de cálculos com scroll
Salva o histórico em arquivo .txt
Suporte a teclado (números, operadores, Enter, Esc, Backspace)
Design responsivo — funciona no celular também
🌐 Acesse online
https://fabiopy-creator.github.io/calculadora

🚀 Como usar localmente
Baixa o arquivo calculadora.html e abre no navegador — sem instalar nada!

🛠️ Tecnologias
HTML5
CSS3 (animações, variáveis CSS, dark theme, Google Fonts)
JavaScript puro (sem jQuery, sem frameworks)
📚 Conceitos de programação usados
Funções e variáveis
Condicionais (if/else)
Eventos de teclado e clique
Manipulação do DOM
Tratamento de erros (divisão por zero, raiz de negativo)
Download de arquivo pelo navegador
